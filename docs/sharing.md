# Sharing with ChatGPT

**Design information for a feature in development. This is not the final launch privacy policy.**

The intended first release shares only explicitly selected items and these fields: item identifier, name, category, lifecycle status, and warranty/return dates you explicitly enable for sharing.

Receipts, document files, photographs, extracted text, prices, barcodes, locations and contacts are outside the initial sharing scope. Connecting does not automatically select existing inventory. Document sharing between Pixel Ledger apps is a separate feature and does not authorize ChatGPT sharing.

The hosted integration processes selected data to answer requests. It is therefore not end-to-end encrypted against that service. Authentication and account isolation must protect each user's data. Public documentation does not grant access to a user's account or inventory.

ChatGPT may display returned information in a conversation. Removing an item from the shared selection or disconnecting cannot erase copies already present in those conversations. Consult ChatGPT's own controls and policies for conversation handling.

Category changes remain suggestions until the user reviews and saves them in MYNVENTORY. The released feature must reject stale suggestions and prevent duplicate application after retries.

Launch requires published support/privacy information, verified connection and deletion behavior, and successful testing in ChatGPT and on the phone. This repository does not claim those launch requirements are complete.
