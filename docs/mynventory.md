# MYNVENTORY with ChatGPT

**Planned feature. Not available for public connection yet.** The instructions below describe the intended experience; labels may change before release.

1. Open MYNVENTORY Settings → AI assistants → ChatGPT when the released app makes it available.
2. Read the sharing explanation and sign in through the official connection flow.
3. Select the inventory items you want to share. Selection starts empty. Preview the fields before synchronizing.
4. Connect the separately published MYNVENTORY integration in ChatGPT using the same account. A verified directory link will be added here after publication.
5. Ask about the selected inventory. Answers use the last synchronized snapshot, which may differ from the current phone state.
6. Review category suggestions inside MYNVENTORY. Nothing is saved to your inventory until you approve it in the app.

Planned questions include finding selected items, listing recorded warranty/return dates and suggesting a category. Missing dates are not inferred. Suggestions cannot silently change your inventory.

If information is out of date, synchronize again. If you changed an item after a suggestion was created, refresh and review a new suggestion. Check the account and current selection if an item is absent.

Disconnecting is intended to remove the integration's shared cloud snapshot and pending suggestions. Content already returned in ChatGPT conversations is managed separately in ChatGPT. Final deletion and retention details will be published with the launch policies.
