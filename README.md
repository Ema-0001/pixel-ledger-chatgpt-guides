# Pixel Ledger · ChatGPT integrations

Public user documentation for separate Pixel Ledger integrations with ChatGPT.

**Status: in development. MYNVENTORY is first. There is no public installation link or downloadable plugin release here yet.** This repository is not an announcement of availability or approval by OpenAI.

## MYNVENTORY

The planned integration helps you find selected inventory items, check recorded warranty/return dates and suggest category changes. Suggestions require review and saving in MYNVENTORY.

- [Planned setup and usage](docs/mynventory.md)
- [Sharing and privacy explained](docs/sharing.md)
- [Synthetic example prompts](examples/mynventory.md)
- [Release status](release-status.json)

DOKIVAULT, MYCOMMIT, WISHNEXT, REALMILY and MONPATH are planned as separate integrations. Existing StillMore and In Memoriam integrations are outside this repository.

## What this repository contains

User guidance, synthetic examples and public release status only. Backend source, deployment configuration, credentials, reviewer accounts and customer records are maintained separately. This repository does not deploy or test the private backend.

An Android app update and a ChatGPT directory listing are separate releases. Uploading an APK/AAB does not publish a ChatGPT integration. This page will link to a verified listing only after the complete connection and approval flow passes testing and publication is complete.

## Reporting problems

Use the support contact shown in the installed app for account or private-data problems. Do not post passwords, tokens, receipts, inventory exports or personal screenshots in public issues. For a general documentation correction, describe only the page and the correction needed.
